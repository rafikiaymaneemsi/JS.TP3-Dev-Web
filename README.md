# TP3 - Objets et tableaux JavaScript

Ce travail pratique couvre la création et la manipulation des objets et des tableaux en JavaScript.

## Structure

- `index.html` : interface de présentation et boutons des exercices
- `css/style.css` : feuille de style
- `js/main.js` : point d’entrée et association des fonctions aux boutons
- `js/exercice1` à `js/exercice6` : modules des exercices
- `js/exercice1/objets.js` à `js/exercice6/objets.js` : objets et tableaux propres à chaque exercice
- `js/utils/affichage.js` : fonctions communes d’affichage

## Exécution

Ouvrir `index.html` avec Live Server ou un serveur local, puis sélectionner les exercices depuis l’interface.
